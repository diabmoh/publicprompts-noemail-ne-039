# Contribution Guidelines

Thanks for helping keep this list useful. Please follow these rules when adding or editing entries.

## Adding a resource

- Use the format: `- [Name](url) - Description ending with a period.`
- Place the entry in the most fitting section, at a sensible position (not necessarily last).
- Descriptions should be factual and concise (one sentence, no marketing superlatives).
- Link to the canonical URL (no tracking parameters, no redirects).

## What qualifies

- The resource is live, actively maintained, and useful for discovering or learning about AI tools.
- Directories and databases should have substantial coverage, not a handful of affiliate links.
- No paywalled-only resources unless they are clearly best-in-class.
- No link shorteners, no duplicate entries.

## Pull request checklist

- One resource per pull request when possible.
- PR title: `Add <Name>`.
- Check that the link returns HTTP 200 and the description matches what the site actually does.
- Run a spell check on your changes.

## Removing or updating entries

If a resource goes offline, pivots away from AI discovery, or degrades into an ad farm, open a PR to remove it and briefly explain why.
